## Brand & Style

This design system establishes an ultra-premium, mission-critical digital portfolio for elite cybersecurity practitioners and systems developers. Rooted in high-trust defense engineering, tactical observability, and refined contemporary glassmorphism, it transcends basic developer portfolios to evoke the precision of sovereign security command centers.

### Target Audience & Emotional Impact
- **Audience:** C-suite security leadership (CISOs, VPs of Infrastructure), technical hiring managers, vulnerability disclosure programs, and defense engineering peers.
- **Impression:** Tactical authority, deep architectural competence, rigorous cryptographic integrity, and unmatched modern sophistication.

### Design Movement & Aesthetic Pillars
- **Obsidian Dark Surface Architecture:** Rich, layered depths rooted in `#080E1A` and `#0B1120`, avoiding flat monochromatic blacks in favor of atmospheric deep-space telemetry tones.
- **Luminescent Telemetry:** Sharp laser cyan and electric sky accents layered with emerald status beacons and ethereal violet perimeter gradients.
- **Tactical Frosted Glass:** Low-opacity, backdrop-filtered containers featuring ultra-crisp 1px hair-thin directional borders that simulate glowing polarized optical glass.
- **Terminal Precision:** Clean typographic harmony pairing geometric modern sans typography with razor-sharp monospaced technical telemetry.

## Colors

The palette establishes high chromatic discipline against layered obsidian depths. Rather than overpowering the interface, saturated highlights serve as telemetry signals, focus rings, and high-value metric signifiers.

### Role Architecture
- **Primary (`#00F0FF`):** Hyper-focused laser cyan. Dictates core primary actions, glowing terminal borders, critical focal stats, and dynamic interactive states.
- **Secondary (`#38BDF8`):** Atmospheric sky blue. Applied to supporting UI indicators, sub-headings, interactive chips, and code syntax keywords.
- **Tertiary (`#8B5CF6`):** Quantum violet. Reserved for secondary accent gradients, specialized cryptography highlights, and credential tags.
- **Neutral Base (`#080E1A`):** Obsidian navy canvas providing infinite visual depth, balanced against stacked modular glass surfaces (`#0B1220` and `#131E33`).

### Semantic Telemetry Signals
- **Status Secure (`#10B981`):** Operational integrity, hardened systems, uptime indicators, and verified security accreditations.
- **Status Warning (`#F59E0B`):** Vulnerability alerts, sandbox environments, and pending audits.
- **Status Breach (`#EF4444`):** Threat identification, incident simulation, and critical test boundaries.

## Typography

The typographic hierarchy implements a tri-font structure engineered for technical authority:
1. **Plus Jakarta Sans (Headlines):** High-density geometric letterforms featuring balanced modern terminals that anchor critical titles without stylistic fatigue.
2. **Inter (Body Copy):** World-class readability across dark OLED backdrops; engineered for technical narrative, case studies, and architectural breakdowns.
3. **JetBrains Mono (Telemetry & Code):** Authentic command-line cadence reserved for security payloads, protocol badges, metric tickers, and status labels.

### Typographic Hierarchy Rules
- High-level headlines (`display-hero`, `headline-xl`) leverage tightened letter-spacing (`-0.03em` to `-0.025em`) to emphasize industrial weight.
- Technical badges and status telemetry consistently utilize uppercase transformations with expanded tracking (`0.08em`) to reinforce security monitor cues.
- Line heights prioritize generous breathing room (`1.5` to `1.6`) on dark backdrops to prevent optical halation and ocular fatigue.

## Elevation & Depth

Visual depth is achieved through an optical sandwich of ambient backdrop blurs, dark surface tint tiers, and luminescent 1px boundary highlights. Heavy drop shadows are replaced with optical glow fields.

### Elevation Hierarchy
- **Level 0 (Canvas Base):** Solid `#060A12` obsidian backdrop overlaid with an extremely subtle radial gradient mesh (`rgba(0, 240, 255, 0.03)` at top-right and `rgba(139, 92, 246, 0.03)` at bottom-left).
- **Level 1 (Structural Glass Panels):** `rgba(11, 18, 32, 0.70)` surface fill combined with `backdrop-filter: blur(16px)` and a crisp 1px perimeter border rendered in `rgba(255, 255, 255, 0.06)`.
- **Level 2 (Interactive Floating Cards):** `rgba(19, 30, 51, 0.75)` surface fill, `backdrop-filter: blur(24px)`. On hover, the top border illuminates with a linear gradient of `#00F0FF` fading into transparent slate.
- **Level 3 (Command Terminals & Modals):** Solid-backed frosted obsidian `#0E1726` bordered by an inner ambient cyan trace glow (`box-shadow: 0 0 35px -5px rgba(0, 240, 255, 0.12), 0 20px 25px -5px rgba(0, 0, 0, 0.65)`).

### Edge & Glow Styling
- Never use heavy drop shadows. All elevation must be felt via the physical contrast of the surface tint and the hair-thin 1px border gradient.
- High-priority elements incorporate telemetry rim lighting (`border: 1px solid rgba(0, 240, 255, 0.25)`).

## Shapes

The design system adopts a calibrated technical curve profile (`roundedness: 2`), delivering contemporary elegance without appearing excessively playful or toy-like.

### Token Application
- **Micro UI Elements (0.375rem / 6px):** Code snippets, inline pill dots, status indicators, and keyboard shortcut glyphs.
- **Standard UI Elements (0.5rem / 8px):** Form input fields, terminal prompt boxes, and interactive utility buttons.
- **Surface Containers (1rem / 16px):** Project cards, skill metric containers, and experience timeline nodes.
- **Hero & Command Cards (1.5rem / 24px):** Primary terminal window consoles and featured engineering spotlights.
- **Full Pills (`9999px`):** Status indicators, technical taxonomy tags, and specialized CTA pills.

## Components

### Buttons
- **Primary Telemetry CTA:** Solid `#00F0FF` background with high-contrast `#060A12` bold typography. Features an ambient neon cyan underglow (`box-shadow: 0 0 20px rgba(0, 240, 255, 0.35)`). On hover, scale shifts by `1.02` with an amplified outer aura.
- **Secondary Ghost / Border Button:** Frosted glass interior (`rgba(255, 255, 255, 0.03)`), 1px border in `#38BDF866`, font colored `#F8FAFC`. On hover, border brightens to `#00F0FF` and background shifts to `rgba(0, 240, 255, 0.08)`.
- **Terminal Action Button:** Full-monospaced minimal button featuring an animated leading prompt symbol (`>_ run_exploit`).

### Chips & Technical Badges
- Constructed with `JetBrains Mono` font at `0.6875rem` uppercase.
- Encased in a pill-shaped container with an ultra-thin 1px border. 
- Prefix incorporates a pulsing 6px circular LED status indicator (`#10B981` for active/verified, `#00F0FF` for protocol/stack, `#8B5CF6` for certification).

### Cards & Glass Panels
- Built with multi-layered glass (`backdrop-filter: blur(20px)` over `#0B1220B3`).
- Bound by a continuous 1px edge stroke featuring directional lighting (brighter at top-left, darker at bottom-right).
- Mouse-tracking spotlight effects: Cards dynamically illuminate with subtle radial gradient overlays on cursor position (`rgba(0, 240, 255, 0.06)`).

### Input Fields & Terminal Consoles
- Grounded in obsidian inputs (`#080E1A`) with subtle inset borders (`#1E293B`).
- On focus, transition border seamlessly to `#00F0FF` with a tight glowing ring (`0 0 0 2px rgba(0, 240, 255, 0.2)`).
- Terminal inputs feature a blinking monospace cursor block in electric cyan.

### Checkboxes & Toggle Controls
- Custom square components with 4px corner rounding.
- Checked state activates a vibrant radial fill of `#00F0FF` with a crisp `#060A12` checkmark icon.
- Toggles utilize a sleek mechanical slider with dark track beds and glowing illuminated neon switches.

### Specialized Components: Security Telemetry Bar & Metric Dials
- **Telemetry Gauge:** Replaces generic circular progress bars with segmented, vector-based HUD telemetry arches utilizing gradient fills (`#00F0FF` to `#38BDF8`) over indexed grid marks.
- **Terminal Shell Window:** Includes authentic window control chrome dots (red, yellow, green) paired with active session telemetry details (`bash - security@kernel:~`).
